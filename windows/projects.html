Topology-Enhanced Video Classification

Conducted research investigating the use of topological data analysis to enhance video classification with 3D convolutional neural networks (3D-CNNs).

Developed a pipeline for extracting topological features from video frames using persistent homology and persistence images, then incorporated these features into multiple model architectures through concatenation-based fusion and multi-branch architectures. Additionally, implemented Convolutional Block Attention Modules (CBAM) to investigate the use of attention mechanisms for processing topological features. Models were trained and evaluated on the UCF101 human action recognition dataset using standard classification metrics.

Stock Fundamentals Reporting Tool

Built a Python-based tool that uses yfinance to automatically collect market data, financial statements, and valuation metrics over a five-year period. The tool generates structured PDF reports that provide a comprehensive overview of a company’s financial health.

Users can enter a stock ticker to instantly generate a detailed analysis of the company. An example report using Google stock data can be viewed by clicking the button below.

UVic Bulletin Board

Early-stage group database project developed for CSC 370: Database Systems at the University of Victoria. The project is a bulletin board platform designed for UVic students to share posts and events, connect through groups, and interact with content within the platform. The system is being designed and implemented using SQL.
